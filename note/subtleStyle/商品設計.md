# 訂閱配豆服務 — 商品設計

把 [subtleStyle](subtleStyle.md) 的「不解釋」與 [brandStrategy](brandStrategy.md) 的「主理人選豆＝飛輪核心」落地成具體商品。

> 設計原則：**讓商品本身是品牌承諾的證據**——而不是用文案說自己很講究。

---

## 一、商品本體

### 三條商品線（一條主軸＋兩條入口）

| 商品線 | 內容 | 對應 TA | 價位帶 |
| --- | --- | --- | --- |
| **主理人月配 Curator's Pick**（主軸） | 每月 1–2 支咖啡豆（200g），主理人選定，附手寫風味卡 | 已有咖啡品味、想被「養」的訂閱者 | NT$680（單支）／NT$1,280（雙支） |
| **杯測日記 Cupping Journal**（深度） | 每月 3 支豆，各 50g 小包，附 SCA 評分卡 | 想練盲飲、訓練味覺的進階愛好者 | NT$880／月 |
| **試水溫 Single Pick**（入口） | 非訂閱、單次購買的限量精選 | 新客體驗、送禮 | NT$420–520／支 |

> 設計邏輯：**主軸吃 LTV（終身價值），深度養死忠，入口轉新客**。三條互為漏斗，不互搶營收。

### 訂閱機制（subtleStyle 的克制應用）

* **不選風味、不選產地、不選莊園**——你只回答**一題**：「淺焙／中焙／不挑」。
* 不挑的人占多數時，主理人有最大選品自由——這正是品牌價值所在。
* 訂閱頻率：每月 1 次。**不做週配**——與克制氣質衝突，且新鮮烘焙無法支撐。

### 進場與離場（friction 設計）

* **進場**：第一個月寄出時附「主理人筆記」實體小冊（4 頁），介紹這支豆為什麼被選中。**這是補新手品味的 Hero 內容入口**，呼應 brandStrategy 第三節「不解釋」的雙面刃對策。
* **離場**：無綁約、隨時可暫停。但暫停時主理人會寄一份「下個月我們會選的方向」預告——**用內容把要走的人拉回來**，而不是用優惠券。

## 二、TA 與痛點

呼應 brandStrategy 的核心受眾：

| TA | 此商品解決的痛點 |
| --- | --- |
| 連鎖咖啡疲勞者 | 不想再喝同一支配方豆，但自己挑又怕踩雷 |
| 設計師／創意工作者 | 想要喝咖啡有「儀式感」，但不想花時間研究 |
| 自己沖咖啡 1–2 年的進階愛好者 | 卡在味覺天花板，需要「比自己更懂的人」帶路 |
| 想送禮給懂咖啡的朋友 | 不知道對方喜歡什麼，但又不想送通用禮盒 |

**核心痛點一句話**：「我想喝得更好，但不想自己變成研究員。」
**本商品承諾**：「主理人替你研究——你只負責喝。」

---

## 三、價值承諾（可被檢視，不只口號）

UVP「不解釋的咖啡」要兌現成**具體可查的規格**：

| 承諾 | 可被檢視的方式 |
| --- | --- |
| 新鮮 | 每包標示**烘焙日期**，承諾出貨前 7 天內烘焙；超過則延後出貨 |
| 透明 | 每包標示：**產地／莊園／處理法／品種／烘焙度／杯測分數** |
| 主理人選品 | 每月公開「為什麼是這支」——50–100 字短評刊在電子報（Hub 內容） |
| 不踩雷保底 | 第一個月若不喜歡，第二包**換豆**；連續兩月不喜歡，無條件退訂並退款 |
| 不打折 | 不做促銷、不做雙 11、不做買一送一——**價格穩定本身就是品味承諾** |

> 為什麼把「不打折」寫進承諾？因為這是品牌資產的一部分。打折一次，「不解釋」的氣質就破功。

---

## 四、首批驗證計畫（接住 brandStrategy 的 🔴 紅燈）

brandStrategy 金錢金字塔指出「營收驗證未過」——Step 3 不能只設計商品，必須落地成可驗證的最小步驟：

1. **預售 50 份「主理人月配」首月**：限量、不公開總額，但內部設停損——20 份以下停手檢討。
2. **收錢再進豆**：用預售金做首批採購，**零庫存風險**。
3. **首三個月只跑主軸**：杯測日記與 Single Pick 等主軸跑順了再開——避免一次燒太多戰線。
4. **每月 AAR**：杯測分數、訂閱續訂率、暫停率、客訴關鍵字——四個數字決定下個月還做不做。

## 五、與既有檔案的一致性

* **[subtleStyle](subtleStyle.md)** = 風格／視覺語言（包裝、官網、電子報的克制感）
* **[brandStrategy](brandStrategy.md)** = 賣給誰、怎麼定位、用什麼框架說
* **[商品設計](商品設計.md)（本檔）** = 真正在賣什麼、怎麼運作、怎麼驗證

三者邏輯一致：**克制的視覺 → 篩選真行家的定位 → 主理人選豆的具體商品 → 預售驗證的營收路徑。**
